## 3. 判断（ユーザー判断、2026-10-12）

| # | 判断 | 内容 |
|---|---|---|
| D3-1 | 不具合を incident として記録する | incident のとおり。汚染の範囲は、実データでの分類が完了するまで UNRESOLVED とし、行数の異常だけで全データの汚染を断定しない |
| D3-2 | 結果の結合を修正する | 日付を突き合わせのキーに含め、日付・場・レース・艇番が一致する行だけを結合する。重複・欠損・日付の不一致を検証する。既存の特徴量とラベルの意味は変えない |
| D3-3 | 検証用の再学習を1回だけ行う | 修正後、手動実行で1回だけ再学習する。生成したモデルは main に自動 commit せず、GitHub Actions の artifact として保存する。学習データ・認証情報を artifact に含めない。学習データを取得できず検証が成立しない場合は、再学習を成功として扱わない |
| D3-4 | 週次の自動再学習を停止する | ユーザーが GitHub の画面からワークフロー「週次モデル再学習」を無効化する（コードは変更しない）。再開は、修正・テスト・D3-3 の結果の確認後、明示の判断による |

### 判断の範囲

- 本判断は、既存の本番モデル（`model_all.pkl`）の置き換えを承認しない。D3-3 の結果を確認した後、別途判断する。
- 本判断は B1（scikit-learn の版固定）の適用を承認しない。D1 は変更しない。
- 本判断は、凍結期間中の週次再学習を「スコア変更」に含めるか（F5）を判断しない。D3-4 の停止は、本不具合への対応として行う。

## 3. 判断内容

1. 現時点では、C8 が Step6-0 §⑤ の G1〜G8 を置き換えるものとは確定しない。
2. 現時点では、C8 が GO 判定とは別の Stage 3 専用の基準として併存するものとも確定しない。
3. したがって、C8 と Step6-0 §⑤ の関係は「判定不能・未確定」とする。
4. この未確定を理由として、§8.6 と §9 の優先順位を新たに決定しない。
5. §8.6 と §9 の優先順位は、引き続き未確定とする。
6. §9 の G3-B・G3-C を、Step6-0 §⑤ の正式G3へ昇格させない。
7. §8.6 の「buy_decision は正式条件外の追加観測項目」とする [B] の既存方針を変更しない。
8. G2改を正式仕様として採用しないとした既存の判断（`docs/上位判断記録_G2_G3_Phase1_20260927.md`）を変更しない。

本判断は、「C8 は Stage 3 専用である」とする判断ではない。既存資料では C8 の正式な位置付けを一方に確定できないため、現状を維持する判断である。

---

## 4. 判断理由

1. C8 は G1〜G8 を「再構成した最終受入基準」とされており（F6）、G1〜G8 との派生関係は記載されている。しかし、C8 が G1〜G8 を置き換えるのか、併存するのかは記載されていない。
2. §11 は GO 判定を G1〜G8 で記載しており（F7）、C8 を GO 判定に用いるとの記載はない。一方、C8 を GO 判定に用いないとの記載もない。
3. C8 の具体的な内容を定めるとされる13章は確認できず（F8）、その内容を推測・復元することはできない。
4. よって、C8 の位置付けは、既存資料から一方に確定できない。

**因果関係**：§8.6 は GO 判定の層（Step6-0 §⑤）について記載し（F1）、§9 は Stage 3 の実測の層から参照されている（F3・F4）。両者が同じ層を規定しているか（したがって優先関係を決める必要があるか）は、C8 が GO 判定の G1〜G8 を置き換えるのか、併存するのかによる。C8 の位置付けが確定しないため、§8.6 と §9 の優先順位も、現時点では決定しない。

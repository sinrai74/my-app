## 2. 変更したファイル

| ファイル | 内容 |
|---|---|
| `odds_fetch.py` | 3連単表のラベル（thead の1着、2着・3着のセル）から組番を読む `_method_labels` を追加。表を認識できたときはその結果だけを返す。数値でないセル（欠場等）の組番はキーを入れない。出現順に割り当てる手法Bは採用しない。表を認識できない場合は、ラベルに基づく旧手法A・Cだけを試す。取得失敗・解析失敗・有効なオッズ0件を WARNING ログで区別する。戻り値の型と失敗時の `{}` は変えない |
| `parsers.py` | `attach_k_results` に引数 `date_col` を追加。指定時は日付もキーに含めて結合し、日付列の欠落・空値、K結果の重複、結合による行数の変化を例外にする。指定しない場合の動作は従来どおり |
| `retrain.py` | 取得した日付を番組表・K結果の両方に `_file_date` として付け、`date_col="_file_date"` で結合する。結合後に `check_label_integrity` で行数・重複・1着の数を検証し、異常なら停止する |
| `.github/workflows/retrain.yml` | 手動実行では `model_all.pkl` と実行ログを artifact（保存14日）に保存し、main へ commit しない。commit は定期実行（schedule）のときだけ行う。定期実行は GitHub の画面で無効化する（D3-4） |
| `test_odds_parser_labels_20261012.py` | 新規。合成 HTML によるテスト13件 |
| `test_retrain_label_date_key_20261012.py` | 新規。合成データによるテスト10件 |

`notify_arashi.py`、Rebuild のコード、設定ファイル、ゴールデン、`model_all.pkl` は変更していない。

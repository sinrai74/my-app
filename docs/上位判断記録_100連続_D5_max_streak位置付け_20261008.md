## 3. 判断内容

### 判断1（D5）

**作業上の streak 計算において、max_streak は、current_streak の更新および satisfied の判定の計算要素として用いない観測上の値とする。**

**max_streak そのものの値の意味・定義、最大値を取る範囲、skip 時・不一致時の扱い、Go/No-Go の判定値としての扱いは、本判断では確定しない。**

ここでいう「観測上の値」は位置付けを示すものであり、max_streak がどのような値であるかを定めるものではない。

### 判断2：判断範囲

| 区分 | 内容 |
|---|---|
| 本判断で確定すること | max_streak を、current_streak の更新の計算要素として用いないこと。max_streak を、satisfied の判定の計算要素として用いないこと。max_streak を観測上の値として位置付けること |
| 本判断で確定しないこと | max_streak の正式な定義。「過去に到達した最大の連続一致数」という意味の採用。最大値を取る範囲（1回の実行、日付をまたぐ範囲、複数の実行、その他）。skip 時・不一致時の max_streak の扱い。max_streak を作業上の Go/No-Go の判定入力に用いるかどうか |

### 判断3：D2 との関係

D2 で確定した、skip 時の current_streak の扱い（増加もリセットもせず、次の比較可能なレースから継続する）は変更しない。

skip 時の max_streak の扱いは、本判断では判断しない。D2 は current_streak についての判断であり、本書は D2 から skip 時の max_streak の扱いを導出しない。

### 判断4：D4 との関係

D4 で確定した、比較可能なレースが不一致となった場合に current_streak を 0 に戻し、その後は 0 から数え直すという扱いは変更しない。

不一致時の max_streak の扱いは、本判断では判断しない。D4 は current_streak についての判断であり、本書は D4 から不一致時の max_streak の扱いを導出しない。

### 判断5：M8-U4 との切り分け

M8-U4（作業上の Go/No-Go の判定値は current_streak か max_streak か）は、本判断とは独立した論点である。本判断は M8-U4 を判断しない。

| 事項 | 本判断での扱い |
|---|---|
| max_streak を streak 計算（current_streak の更新、satisfied の判定）の要素として用いないこと | **確定**（判断1） |
| max_streak を作業上の Go/No-Go の判定入力に用いないこと | **未判断** |
| current_streak を作業上の Go/No-Go の判定値として正式に確定すること | **未判断** |

F5（`GoNoGoCriteria` に max_streak のフィールドがない）および F9（Step6-3-69 §2.1 の供給元の確定）は、現在の実装・資料の事実として記録するにとどめ、Go/No-Go の判定値の正式な根拠としては扱わない。

## 4. 判断理由

1. 現行実装において、current_streak の更新と satisfied の判定は max_streak を参照せず（F2）、max_streak は出力と表示に用いられている（F4）。このため、max_streak を streak 計算の要素から外した観測上の値として位置付けても、P1・D1・D2・D4・D3 のいずれとも矛盾しない。
2. 一方、max_streak の値の意味については、正式な定義がなく（F7・F8）、「到達した最大の連続一致数」とする根拠は現行実装（F1）とテスト（F6）だけである。P2 により現行実装をそのまま正式仕様として採用しないため、値の意味は本判断では確定しない。また、最大値を取る範囲を定めることは、「100連続」の単位（M8-U1〜U3、M8-U1 は FROZEN）と結びつくため、本判断では扱わない。
3. max_streak を Go/No-Go の判定入力に用いるかどうかは、未確定の論点 M8-U4（F10）と一体であるため、本判断では扱わない。

1. 本判断は、max_streak を streak 計算の要素として用いないという位置付けだけを確定する。max_streak がどのような値であるかは確定しない。

| 用語 | 本書での意味 |

| レース単位の skip | 対象レース（eval_id）について、レース全体の比較が行われず、比較不能として skip されること |

## 3. 判断内容

### 判断1（D2）

**作業上の streak 計算・観測において、レース単位の skip は streak の判定対象外とする。skip によって current_streak を増加させず、またリセットもしない。次の比較可能なレースから、それまでの streak を継続して数える。**

この判断による扱いは、次のとおりである。

| 項目 | 扱い |
|---|---|
| current_streak | skip によって +1 しない。skip によって 0 に戻さない |
| matched・diff | skip された eval_id は、いずれにも入れない |
| broken | skip された eval_id は、broken として扱わない |
| skip の後 | 次の比較可能なレースで、skip より前の current_streak から継続する |

### 判断2：本判断で固定するものと固定しないもの

1. 本判断で固定するのは、**レース単位で比較不能として skip された eval_id を、作業上の streak の判定から除外し、streak を維持する**という扱いである。
2. 本判断は、現在確認されている skip の発生経路（F3 の①・②）を、将来にわたって変わらない skip の原因として固定するものではない。
3. skip の理由の分類、将来の原因の追加、原因ごとの扱いは、必要であれば別に判断できる状態を維持する。
4. 本判断は、段単位の未比較（§1.1）を対象としない。
5. 本判断は、broken の定義（D3）そのもの、および current_streak・max_streak の定義（D4）そのものを定めない。

---

## 4. 判断理由

1. 正式条件には skip の扱いが明記されておらず、Shadow の skip の正式な定義もない（F1・F2）。P1 により、本判断は作業上の streak 計算・観測を対象とし、正式条件を変更しない。
2. D1 により1件の粒度は eval_id とされ、skip の算入は別の問題として残されている（F8）。本判断はその問題について、レース単位の skip を作業上の streak の判定から除外することを定める。
3. skip されたレースは比較が行われていないため、一致・不一致のいずれの結果も持たない（F3・F4）。このため、streak を増やす根拠も、0 に戻す根拠も持たないものとして扱う。
4. 現行実装も、skip された eval_id を record せず、streak を変化させずに継続している（F4〜F6）。ただし、本判断は現行実装を正式仕様として採用したものではない（P2）。

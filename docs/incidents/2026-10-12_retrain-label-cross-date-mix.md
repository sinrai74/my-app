### 2.2 合成データでの再現（リポジトリ外の検証）

- 同じ場・同じレース番号の2日分を `attach_k_results` に渡すと、1レースに1着が2艇できた。
- 前提（1場15日開催・1日12レース・1号艇の1着率55%）を置いた試算では、行数が約7.5倍になり、正しいラベルと一致する行は約68%だった。1着ラベルの割合は約1/6から約1/3に増え、外側の艇ほど1着が水増しされた。この数値は仮定に基づく試算であり、実データの値ではない。

## 3. 推定・未確定事項（事実ではない）

- **汚染の範囲**：28日分の B・K ファイルを照合できていないため、実データで重複・混在・欠損を分類できていない。行数の異常（§2.3）は日付をまたいだ結合を示すが、**全行が誤ったラベルであるとは断定しない**。
- **予測への影響の大きさ**：未確定。修正版で学習し直して比較しないと定量化できない。
- **凍結前のモデル（F8）への影響**：未確定。
- ⑳20.2 に再学習への言及はなく、凍結期間中の週次再学習を「スコア変更」に含めるかは未判断である（`docs/上位判断記録_整合性レビュー対応方針_20261009.md` §5）。

## 4. 対応方針（`docs/上位判断記録_再学習ラベル混在_20261012.md` による）

- 結果の結合に日付を含め、日付・場・レース・艇番が一致する行だけを結合する。重複・欠損・日付の不一致を検証する。
- 検証用の再学習は1回とし、モデルを main に自動 commit せず、GitHub Actions の artifact として保存する。本番のモデルは自動で置き換えない。
- 週次の自動再学習は、ユーザーが GitHub の画面から無効化する。再開は、修正・テスト・1回の再学習結果の確認後、明示の判断による。
- ゴールデンは ⑳20.3 の条件を免除しない（現行のゴールデンは ML を通らないため、変更前後の比較結果を記録する）。

## 5. 暫定対応

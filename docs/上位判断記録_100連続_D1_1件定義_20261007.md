## 3. 判断内容

### 判断1（D1）

**作業上の streak 計算・観測における「1件」の粒度は、1レースを識別する eval_id（＝対象レース）とする。**

### 判断2：本判断の範囲

1. 本判断は、「1件」の**粒度だけ**を定める。
2. **「1件＝1レース（eval_id）」と決めることと、「skip された1レースを streak に算入する」と決めることは、別の問題である。** 本判断は、skip された eval_id を streak 上の1件として数えるかどうかを決めない。
3. 本判断は、1件について何をもって一致・不一致とするか（どの比較段を含めるか、一致の基準）を決めない。
4. 本判断は、Step6-0 §⑤ の正式G2・G3 の完了条件を変更・再定義しない。

---

## 4. 判断理由

1. 正式条件の文言は「100レース連続ゼロ」「100レース連続でRaceEvaluation差分ゼロ」であり、数える単位を「レース」と表している（F1・F2）。
2. eval_id は、Phase0.5 で対象レースの識別子として正式に定義されている（F3）。
3. Step6-0 は、Shadow を「1レース分」の流れとして扱い、同一の対象レースについて各段を比較している（F4）。
4. 現行実装も、TARGET_RACES → eval_id を単位として比較・`record()`・streak の集計を行っている（F5）。ただし、本判断は現行実装を正式仕様として採用するものではない（P2）。
5. ほかの候補（RaceEvaluation 単位、複数の段をまとめた1評価単位）は、いずれも同じ eval_id＝1レースの粒度であり、粒度として別の定義を必要としない（F3・F4）。

## 7. Shadow・Stage 3 との関係

- 0003（B1）: Shadow は既に scikit-learn 1.5.2 で動いている。Legacy 側の比較値は git に保存された `sent_*.txt` から読む。B1 による Shadow の比較条件の変化は確認されない。
- 0002（B3）: 変更は `_run_main()` の既定日付だけで、Shadow（`rebuild/actions/shadow_entrypoint.py`）は `_run_main()` を呼ばない。
- motor_history の重複除去: Shadow の Rebuild 側は `x_venue_stats` で場別統計を作る。`shadow_run.yml` には GITHUB_TOKEN がないため、Release からの取得は行われず、checkout した git 版 `motor_history.csv` が使われる（コード上の確認）。したがって重複除去により、Shadow の Rebuild 側の場別統計が変わる。ただし `motor_history.csv` は毎日追記されており、Shadow の Rebuild 側の入力が日々変わる点は従来と同じ。
- Stage 3 の既存の観測記録は、当時の条件での記録として保持する（本書は改訂しない）。

## 4. USER DECISION（本書の判断）

### 判断1

**継続基準書 §8.5 [B] の作業上の streak 計算・観測において、作業上の Go/No-Go の判定入力としては、当該判定に際して保持されている current_streak を用いる。**

### 判断2：判断の性質

**current_streak を作業上の Go/No-Go の判定入力として採用することは、既存資料からの導出ではなく、本書におけるユーザーの判断である。** 現行実装が current_streak を用いていること（F1）は事実として記録するが、本判断は、現行実装を根拠として正式仕様化したものではない（P2）。

### 判断3：本判断の帰結として明記する事項

1. 本判断により、作業上の範囲において、Go/No-Go の判定入力は、判定に際して保持されている連続一致数（current_streak）となる。これは、作業上の範囲で「判定に際して連続が継続していること」を見る読み方を選ぶものである。ただし、本判断は、正式G2・G3 の「100レース連続」の意味を定めるものではない。
2. 本判断の結果として、作業上の Go/No-Go の判定入力に max_streak は用いられない。これは本判断（M8-U4）の帰結であり、D5記録の判断内容を変更・拡張するものではない。max_streak の正式な意味・最大値を取る範囲は、引き続き定めない。

## 3. 判断内容

### 判断1（D3 のうち、位置付け）

**作業上の streak 計算および作業上の Go/No-Go の判定において、broken・broken_at は、判定入力または streak 計算の要素として用いない観測上の記録とする。**

**broken・broken_at が具体的に何を記録するものか、その記録内容の意味・定義は、本判断では確定しない。**

### 判断2：判断範囲

| 区分 | 内容 |
|---|---|
| 本判断で確定すること | broken・broken_at を、current_streak・max_streak の計算要素として用いないこと。broken・broken_at を、作業上の Go/No-Go の判定入力として用いないこと。broken・broken_at を観測上の記録として位置付けること |
| 本判断で確定しないこと | broken・broken_at の記録内容（「不一致の一覧」か、「streak が途切れた地点」か、その他か）。broken と diff を同一とみなすかどうか。broken_at の正式な意味・件数の定義。broken_at の表示方法 |

### 判断3：D4 との関係

D4 で確定した「比較可能なレースが不一致となった場合、current_streak を 0 に戻し、その後は 0 から数え直す」という扱いは、broken・broken_at の記録内容の意味とは独立して成立する（F1）。本判断は D4 を変更しない。

### 判断4：Go/No-Go との関係

broken・broken_at は、作業上の Go/No-Go の判定入力に用いない（F2）。

ただし、本判断は、次のいずれも定義しない。

- No-Go とは何か
- 不一致（diff）と No-Go がどう関係するか
- Go/No-Go の判定に何を入力とするか（current_streak と max_streak のどちらを判定値とするかを含む）
- Go/No-Go の条件全体

### 判断5：D2 との関係

D2 の判断（レース単位の skip は matched・diff・broken のいずれにも入れない）は変更しない。本判断は broken_at の記録内容を定義しないが、D2 による「skip された eval_id は broken として扱わない」という扱いは、そのまま維持される。

## 4. 判断理由

1. current_streak・max_streak の更新は broken_at に依存しない（F1）。また、broken_at は作業上の Go/No-Go の判定に渡されず、表示と出力にだけ用いられている（F2〜F4）。このため、broken・broken_at を判定入力・計算要素から外した観測上の記録として位置付けても、P1・D1・D2・D4 のいずれとも矛盾しない。
2. 一方、broken・broken_at の記録内容の意味については、正式な定義がなく（F7）、「不一致の一覧」とする根拠は現行実装（F5）だけであり、「streak が途切れた地点」とする根拠は名称だけである（F6）。P2 により、現行実装をそのまま正式仕様として採用しないため、記録内容の意味は本判断では確定しない。
3. 位置付けだけを確定することで、`docs/上位判断記録_G2_G3_Phase1_20260927.md` §2.2 に残る「broken の扱い」（F8）のうち、streak 計算と判定入力との関係を、記録内容の意味に踏み込まずに整理できる。ただし、本判断によって同 §2.2 の「skip / broken の扱い」全体が確定したものではない。

## 3. 判断内容

### 判断1

**継続基準書 §8.6 と §9 の優先順位は、現時点では決定しない。** 既存の状態を維持する。

### 判断2：理由

1. §8.6 と §9 の間に、明示的な優先規定がない（F7）。
2. 両者はいずれも [B] であり、区分上の上下がない（F8）。追加時期の前後も優先の根拠にならない（F9）。
3. §8.6 と §9 が同じ層を規定しているか、別の層を規定しているかは、C8 の位置付けを含めて確定していない（F6・F10）。
4. C8 の内容を定めるとされる13章が存在しない（F6）。
5. したがって、一方を優先することは、既存資料から導ける判断ではなく、新たな仕様・優先規則を作ることになる。

### 判断3：本判断の意味

本判断は、次のいずれでもない。

- §8.6 を否定する判断
- §9 を否定する判断、§9 を無効化する判断
- §8.6 を正式G3の変更として採用する判断
- §9 の G3-B・G3-C を正式G3へ昇格させる判断

本判断は、両者の優先順位を現時点では決めず、既存の状態を維持する判断である。
